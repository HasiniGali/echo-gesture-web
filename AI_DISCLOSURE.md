# AI Disclosure

## Project Name
EchoGesture — Real-Time Sign Language Gesture Recognition and Communication System

## Use of Artificial Intelligence

AI tools, including ChatGPT, were used during the development of EchoGesture to support the project team in the following areas:

- **Code Assistance and Debugging:** AI was used to assist with code generation, understanding errors, troubleshooting, and improving implementation across the frontend and backend.
- **Technical Guidance:** AI provided guidance on integrating the React frontend with the FastAPI backend, configuring API communication, and deploying the application.
- **Documentation:** AI assisted in preparing and improving the README, project descriptions, setup instructions, and technical documentation.
- **Presentation Preparation:** AI assisted in organizing project information, explaining the system architecture, summarizing performance results, and preparing presentation content.

## Human Contribution and Responsibility

The project team designed, implemented, integrated, tested, and deployed the EchoGesture application. AI-generated suggestions were reviewed and adapted as needed.

The team is responsible for the final source code, implementation, reported results, and submitted materials.

AI tools were used as supporting resources and did not replace the team's development, testing, or decision-making.

## Transparency Statement

The use of AI tools is disclosed transparently. The project does not claim AI-assisted work as entirely unaided human work.
